# Phase 12: Multi-Variable Sheffer Discovery (Plan 12-01)

## Objective
Extend the EML engine to handle multi-variable input functions (mEML) as primitive nodes. This includes upgrading the discovery engine to sample N-dimensional spaces and deriving 2D primitives like addition and multiplication from pure Sheffer compositions.

## Tasks
1. [ ] **Variable Analysis**: Implement automatic variable detection in `target_expression` strings using AST.
2. [ ] **N-Dimensional Sampling**: Upgrade `DiscoveryEngine` to generate N-ary point sets for signatures and MSE calculation, ensuring functional distinctness in bivariate space.
3. [ ] **Multi-Variable Discovery**: derive `add(x, y)` and `multiply(x, y)` using the updated engine.
4. [ ] **Registry Support**: Ensure the formula database and compiler correctly handle substitutions for N-ary functions.

## Technical Details
- Currently, `DiscoveryEngine` is univariate-biased (only iterates over `x`).
- `to_signature` in `EMLNode` needs to be updated to accept multi-variable test point sets.
- `safe_eval_math` should be generalized to accept arbitrary variable maps.

## Verification Plan
- [ ] `eml_discover(target_expression='x + y')` should produce a tree with MSE < 1e-8.
- [ ] `eml_discover(target_expression='x * y')` should succeed.
- [ ] Unit tests for multi-variable signature matching.
