# Requirements Archive: v2.0 (Discovery Optimization & Symbolic Regression)

**Archived:** 2026-04-16

## v2 Requirements (Complete)

### Symbolic Regression (SR)
- [x] **SR-01**: Master formula tree supports differentiable weights optimized via Adam against numerical targets.
- [x] **SR-02**: Weight snapping logic recovers exact discrete nodes from optimized floats with 1e-4 tolerance.

### Discovery & Optimization (DISC/COMP)
- [x] **DISC-04**: Rank formulas by structural simplicity using Tree Edit Distance (TED).
- [x] **COMP-01**: Support for deep functional compositions including trigonometric and hyperbolic primitives.
- [x] **COMP-02**: Distributed discovery using `multiprocessing` to handle large composition depths (D > 4).

### EML-Transformer (MODEL)
- [x] **MODEL-01**: `EMLCompiledFFN` module translates EML binary trees into a computation tape.
- [x] **MODEL-02**: High-precision complex arithmetic support for internal transformer weights.
- [x] **MODEL-03**: Forward pass parity test: Transformer output matches symbolic tree output within 1e-12.
- [x] **MODEL-04**: Functional Basis Attention: Attention heads mapped to specific discovered formulas (e.g., sin, exp).
- [x] **MODEL-05**: Recursive Token Injection: Formulas can leverage previously discovered identities as unit tokens.

## Requirement Outcomes
All v2 requirements were validated. The EML-Transformer prototype exceeded efficiency targets, requiring significantly fewer parameters for function approximation than standard MLPs.
- **Adjustments:** Complex-mode was simplified to use `torch.complex128` natively.
- **Dropped:** None.
- **Deferred:** Performance optimization (torch.compile) moved to v3.0.
